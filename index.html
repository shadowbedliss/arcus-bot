ARCUS public web view

This version is designed for free static hosting such as GitHub Pages, Netlify, or Wasmer. It reads the committed data file and shows the current operation overview without needing the Node bot process.

If you need live editing or bot-to-web sync, the Node backend is still required for the write path.

Guild filter

Enter a guild ID to limit the view to that server, or leave it blank to show everything.
